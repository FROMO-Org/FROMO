# Appendix & Timesheet

Supporting project material for evaluation, organised by category rather than dumped flat.

## Structure

```text
Appendix_Timesheet/
├── timesheet/             # Team timesheet(s)
├── mockups/               # MVP mockups / design material
├── architecture/
│   ├── backend/           # Backend architecture docs/diagrams
│   └── frontend/          # Frontend (web + mobile) architecture docs/diagrams
├── User Interviews Q&A/   # Anonymised interview transcripts/Q&A
└── other/                 # Anything that doesn't fit the above
```

Drop files into the matching subfolder. If a category needs its own further breakdown (e.g. `mockups/` by screen or `architecture/frontend/` by web vs mobile), add subfolders rather than mixing file types together.

**Before adding anything here:** if a file touches real user research (interview notes, survey responses, participant data), it must be fully anonymised first — no names, emails, or other identifying details — and should state participant count and anonymised demographic info (age range, background, etc.). This repo is public, so anything committed here is public too, and cannot be quietly removed later since the project's commit history is not to be rewritten or squashed.
