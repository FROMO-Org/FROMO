# Appendix & Timesheet

This folder contains the supporting appendix materials for the FROMO project. It is used to document the team's working process, research evidence, design development, architecture decisions, planning records, and timesheet/budget tracking materials.

The main project source code lives in the root repository. This appendix folder is intended as a structured evidence archive for assessment, review, and project traceability.

## Folder Structure

```text
Appendix_Timesheet/
├── Meeting_Notes/          # Weekly meeting agendas, sprint notes, demo notes, and professor meeting records
├── Questionaire/           # User research questionnaire documents
├── User Interviews Q&A/    # Interview questions, answers, and summarised user research findings
├── architecture/
│   ├── backend/            # Backend contribution notes, database diagrams, payment flow, and system architecture
│   └── frontend/           # Mobile/web architecture, testing plans, methodology notes, and references
├── mockups/                # MVP mockups, prototype screenshots, and prototype links
├── other/                  # User stories, work division, Gantt chart, and additional supporting documents
└── timesheet/              # Team timesheets, budget tracking, and business plan material
```

## Contents

### Meeting Notes

The `Meeting_Notes/` folder records the team's weekly collaboration process. It includes sprint meeting notes, agendas, demo notes, professor meeting records, task summaries, and follow-up action items.

These files show how the team planned work, discussed blockers, divided responsibilities, reviewed progress, and adjusted priorities across the project.

### Questionnaire

The `Questionaire/` folder contains the final user research questionnaire used to collect early feedback about the FROMO concept, target users, event discovery habits, and user needs.

### User Interviews Q&A

The `User Interviews Q&A/` folder contains interview questions, interview answer documents, and a summary of findings. These materials support the user-centred design rationale behind FROMO, especially the problem of students missing nearby social opportunities due to fragmented or hard-to-find event information.

### Architecture

The `architecture/` folder documents the technical design of FROMO.

- `architecture/backend/` includes backend contribution notes, database design, system architecture diagrams, and payment flow diagrams.
- `architecture/frontend/` includes mobile and web architecture notes, test plans, methodology evaluation, testing notes, and references.

Together, these documents explain how the system is structured across the backend API, database, mobile client, and web frontend.

### Mockups

The `mockups/` folder contains MVP design materials, including mobile and web mockups and prototype references. These files show the visual and interaction design evolution from early concepts to the implemented product experience.

### Other Supporting Documents

The `other/` folder contains additional project management and planning evidence, including user stories, group work division, and Gantt chart updates.

### Timesheet

The `timesheet/` folder contains the team's time and budget tracking material, including the final business plan and budget tracking spreadsheet. These files provide evidence of workload distribution, planning effort, and project management over the semester.

## Purpose

This appendix is included to make the project process transparent and reviewable. It helps reviewers understand not only the final FROMO implementation, but also the research, planning, design, architecture, testing, and collaboration work behind it.

It includes:

- weekly progress and sprint activity
- team meeting records and decision history
- user research evidence
- interview and questionnaire materials
- design mockups and prototype development
- backend and frontend architecture documentation
- testing and methodology notes
- workload, timesheet, and budget tracking records
